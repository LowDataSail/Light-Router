# Market Positioning

## Market Size
- Professional Racing: 500-1000 teams
- Offshore Cruising: 10,000-50,000 boats
- Research Vessels: 500-1000 vessels

## Competitors
| Tool | Data Usage | AI/ML | Offline | Open Source |
|------|------------|-------|--------|------------|
| PredictWind | 200-500 KB/day | No | No | No |
| SailGrib WR | 100-300 KB/day | No | Yes | No |
| StormGeo AWT | 500-1000+ KB/day | No evidence | No | No |
| qtVlm | 500-1000 KB/day | No | Yes | Yes |

## Target Segments
### Primary
- Offshore Racers: need speed, reliability, satellite optimization
- Long-Distance Cruisers: need safety, cost-effectiveness
- Research Vessels: need autonomy, remote operations

### Secondary
- Autonomous Boat Developers: need AI-native, edge-optimized
- Commercial Shipping: need fuel savings, fleet management

## Partnership Goals
- Infoclimat: weather data provider (GRIB2, wave models, real-time forecasts)
- Freewinds.world: testing platform (virtual sailing, validation)
- qtVlm: open-source integration (routing engine, community)
- PredictWind: commercial integration (user base, validation)
- NOAA: public data access (free weather data, global coverage)
- Iridium: satellite partnership (network optimization, bundling)

## Differentiation
- Data efficiency: target <10 KB/day vs industry 100-1000 KB/day
- AI-native: no commercial tool uses AI for routing
- Edge-optimized: Raspberry Pi compatible, <1 Wh/update
- Open source: MIT License
